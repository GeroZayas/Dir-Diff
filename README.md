# Dir-Diff: A directory organizer and cleaner written in Odin

## What is this program?
This small program compares two directories and checks wether they share the same files. It then allows the user what to do with those duplicates. 

## 100% Handwritten by me (Gero Zayas) - No AI
Nothing against AI, as many times have I said, but this is an exercise for the sake of learning and improving my Odin/Low Level Programming skills. I because I just f... love programming, dude.
